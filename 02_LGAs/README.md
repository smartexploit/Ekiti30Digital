# Ekiti State LGAs Geographic Dataset

This folder contains the initial geographic dataset for the 16 Local Government Areas of Ekiti State.

## Purpose

The dataset supports the Explore Ekiti map and other geographic features of EKITI@30 DIGITAL.

## Data Included

Each LGA record contains:

- LGA name
- Headquarters
- Approximate headquarters coordinates
- Major towns and communities
- Notable places
- Important institutions
- Source information
- Verification status
- Contributor

## Coordinate Standard

Coordinates use decimal degrees in the WGS84 coordinate system.

The initial coordinates represent approximate headquarters town-centre points. They should not be treated as official LGA boundaries.

## Verification Status

- `Pending`: Information has been collected but requires checking.
- `Reviewed`: The source and location have been checked.
- `Verified`: The information has been independently approved for publication.

## Limitations

Some coordinates, communities, institutions and landmarks remain provisional. These entries must be reviewed before they are published as verified information.
