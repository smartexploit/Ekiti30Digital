# EKITI@30 Photographs

This folder contains photographs collected for the **EKITI@30 DIGITAL**
project. The images support the historical timeline and research records
prepared for the project.

There are **24 photographs** in this collection. Each image is labelled
with its related **EK number** so it can be matched easily with the
corresponding timeline or research entry.

## File Naming

The photographs are named using their EK record number followed by a
short description.

Examples:

``` text
EK-002-bawa-first-gov.jpg
EK-013-Afe-Babalola-University.jpg
EK-020-Ikogosi-Warm-Springs-ent.jpg
```

This makes it easier to connect each photograph with its related
EKITI@30 timeline entry.

## Sources

The photographs were collected during the research process from
government and institutional websites, news websites, historical pages,
and publicly available online sources.

The source links used during the research are kept separately for
reference and verification. Where an image has been cleaned or enhanced
for presentation, the historical subject and context should remain
unchanged.

Images with unclear copyright or reuse conditions should be checked
before final public publication.
