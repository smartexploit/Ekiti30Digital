# 16_Media/Culture_Tourism — Member 7

This folder holds the Culture, Tourism & Heritage media for EKITI@30 DIGITAL.

Each subfolder is one inventory entry (CT-001 ... CT-010, more to be added once
the full 27-entry master inventory is available). Inside each entry folder:

- `media/` — the actual image/video files go here (currently empty placeholders)
- `metadata.md` — filled-in submission record in the team's official format
- `sources.md` — where the information/image came from
- `permission.md` — licensing/usage-rights log; do not publish anything until
  this is resolved

Every entry currently has `Verification status: Needs verification` — none of
these are ready to publish yet. As real photos, photographers, dates, and
usage rights are confirmed, update the corresponding `metadata.md` and
`permission.md` and change the status to `Verified`.

Standard: Context + Source + Verification + Permission + Quality > Quantity
