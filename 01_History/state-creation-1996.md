## Summary
Ekiti State was created on 1 October 1996. This record validates the date as stated in the state government's official anniversary statement (SRC-001). While the founding instrument (SRC-002) is noted as a supplementary gap, the Tier A official government declaration is authoritative for the state-creation event.

## Facts
- Ekiti State was created on 1 October 1996. [S1]
