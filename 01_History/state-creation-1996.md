## Summary
Ekiti State was created on 1 October 1996. This draft records the date as stated in the state government's anniversary statement. The founding instrument has not yet been located (SRC-002), so the document stays in draft until the Verification Lead decides whether the statement alone is enough.

## Facts
- Ekiti State was created on 1 October 1996. [S1]
